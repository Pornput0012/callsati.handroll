argument-hint: <ชื่อซอส> <เตือนสติ|ปลอบใจ>
---

เพิ่ม/แก้ซอส: $ARGUMENTS

ขั้นตอน:
1. อ่าน CLAUDE.md (หัวข้อซอส) และ `data/sauces.ts`
2. เพิ่ม entry: id, ชื่อ, รสชาติ, ประเภท (`warning` เตือนสติ / `comfort` ปลอบใจ), ระดับความแรง, สี, ข้อความสั้นบนโปสเตอร์
3. กฎหลัก: ไพ่ดี → ซอสเตือนสติ, ไพ่แย่ → ซอสปลอบใจ ห้ามสลับ
4. อัปเดต mapping ไพ่→ซอสให้ครบทั้ง 22 ใบ (และท่ากลับหัวถ้ามี) ไม่มีใบไหนไม่มีซอส
5. อัปเดตตารางซอสใน CLAUDE.md ถ้ามีการเปลี่ยน
6. รัน `npm run lint`
